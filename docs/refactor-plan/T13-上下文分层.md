## 问题

cortico 喂给宿主 LLM 的上下文 = ENV_PROMPT.md（L0）+ 每轮观察文本（readouts/地图视图等，`world.ts` 的 ENV 组装区与 `proxy.ts` 发送侧）。观察内容每轮全量变化，历史越长 token 越贵且前缀缓存全失效。

## 你的任务

1. **新建 `src/context-layers.ts`**：
   - 四层组装器：`L0 静态前缀`（ENV_PROMPT，永不变）/ `L1 检查点摘要`（**只追加段，永不重写旧段**——避免"摘要的摘要"劣化）/ `L2 原始事件记录`（滚动窗口）/ `L3 现拼尾部`（本轮观察/弹幕快照等瞬时信息）；
   - 预算控制：`budgetTokens` 三水位线（软限开始压缩 L2 → 硬限丢弃最旧 L2 → 溢出报错）；
   - **前缀稳定性断言**：导出 `assertStablePrefix()`——组装两次相同输入，L0+L1 前缀字节级一致（ Amaidesu PrefixGuard 思路）。
2. **接入**：`world.ts` ENV 组装区 + `proxy.ts` 发送侧改为经 context-layers 组装。对宿主的最终载荷内容**语义等价**（首轮观察不变；变化只在长会话的滚动压缩上）。
3. **瞬时信息走尾部**：弹幕快照、当前队列渲染这类只对本轮有意义的内容标为 tail-only（不进 L2 历史）。消费 T5 的 notice-router 输出时按路由通道分流。
4. **新建 `tests/context-layers.test.ts`**：预算三水位线触发顺序、L1 只追加（旧段哈希不变）、tail-only 不进历史、前缀稳定性断言。≥ 12 用例。用 T15 的 botkit 造事件流。
5. **可测量性**：导出各层字符数统计（日志输出），报告里给出改造前后一轮 10 轮会话的上下文增长对比（用测试模拟，不用真跑）。
