规则：

2. `index.ts` 的再导出路径、`package.json` 的 `"main": "./src/index.ts"` 与 cortico 协议字段（`webUiClient` 等）指向的路径逐个核对（dist/ 不在你手里，别碰）。
3. `tests/` 里的 import 同步改。
4. `ENV_PROMPT.md` 等运行时按 `import.meta.url` 读文件的路径（proxy.ts/world.ts 里 `new URL('./ENV_PROMPT.md', ...)`）跟随移动后**必须仍指向正确文件**——grep 所有 `new URL(` 核对。
5. 全部完成后跑一次完整验收（见下）。

## 禁区

- 逻辑改动为零：`git diff main -w --stat` 之外任何"看起来改了逻辑"的 diff 都是违规。用 `git diff -w --find-copies-harder` 自查。
- `describe.json`、`dist/`、`data/` 不动。

## 验收

1. 测试全绿（全量，一次不少）。
2. `ls src/*.ts` 只剩协议层 5 个文件左右；`ls src/` 出现 12+ 子目录。
3. `grep -rn "from '\.\./" src | wc -l` 与 `grep -rn "from '\./" src/core | head` 抽查若干 import 路径真实有效（node 直跑测试即验证）。
4. `node --experimental-strip-types -e "import('./src/index.ts').then(()=>console.log('module loads')).catch(e=>{console.error(e);process.exit(1)})"` 不报模块找不到（协议面可加载）。
