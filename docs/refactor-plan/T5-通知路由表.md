## 你的任务

1. **新建 `src/notice-router.ts`**：声明式路由表。
   ```ts
   export interface NoticeRoute {
     event: string                    // 事件种类，如 'death'、'danmaku'、'night'
     channel: 'observation' | 'queue' | 'note'   // 通道（按 readouts 现有消费方式定）
     template: (ctx: NoticeContext) => string    // 纯函数文案
     dedup?: { key: (ctx: NoticeContext) => string; windowMs: number }  // 同类事件去重
   }
   export const NOTICE_ROUTES: readonly NoticeRoute[] = [ /* 一行一个事件 */ ]
   ```
2. **迁移 `src/readouts.ts`** 中散落的"事件→文案"分支到路由表（renderQueue 等队列渲染不是事件通知，保留原样）。readouts 变成"遍历路由 + 渲染"的薄层。
3. **去重（dedup）机制**照抄 Amaidesu 语义：同 key 事件在窗口期内合并/丢弃——弹幕这类高频事件必须有窗口去重，避免刷屏。
4. **顺便把 readouts 从 executor 的转口解耦**：`readouts.ts:1-2` 现在 `import { renderQueue } from './executor.ts'`——T6 正在删转口，你这边**直接改成从函数真正所在模块 import**（grep 找到 renderQueue 的定义文件直连它），别等 T6 替你改。
5. **新建 `tests/notice-router.test.ts`**：表驱动测试每种事件至少一条（文案生成、dedup 窗口、时钟注入后行为确定）。模板函数注入 fake 时钟，断言跨窗口/窗口内两种行为。
